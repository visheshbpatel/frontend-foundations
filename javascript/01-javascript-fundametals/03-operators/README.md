# Operators in JavaScript

This folder contains notes and practice questions for understanding how operators work in JavaScript.

---

## Files in this folder

### 1. 01-operators.js

Covers different types of operators:

* Arithmetic operators
  addition, subtraction, multiplication, division, modulus, exponentiation

* Comparison operators
  equality, strict equality, inequality, relational operators

* Assignment operators
  shorthand operations like `+=`, `-=`, `*=`, `/=`

* Logical operators
  AND (`&&`), OR (`||`), NOT (`!`)

* Unary operators
  `+`, `-`, `!`, `typeof`, increment and decrement

* Ternary operator
  shorthand for conditional expressions

Also includes:

* Behavior of `==` vs `===`
* How logical operators return values
* Difference between `typeof` and `instanceof`

---

### 2. 02-practice-questions.js

Contains small problems to test understanding:

* Logical conditions using `&&`, `||`, `!`
* Truthy and falsy values
* Nested ternary expressions
* Output prediction questions

Also covers:

* Boolean conversion using `!!`
* Pre-increment vs post-increment behavior

---

## Key Takeaways

* `==` allows type coercion, `===` does not
* Logical operators return actual values, not just true or false
* Ternary operator is a compact alternative to if-else
* Understanding truthy and falsy values is essential for conditions
