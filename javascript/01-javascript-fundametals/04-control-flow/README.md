# Control Flow in JavaScript

This folder focuses on how JavaScript controls the execution of code using conditions and decision-making structures.

The aim is to understand how different control statements behave and how to write clean, readable logic.

---

## Files

### 01-control-flow.js

Covers core control flow concepts:

* if, else if, else
* switch case
* early return pattern

Also includes:

* when to use if vs switch
* how break works in switch
* writing cleaner conditions using early returns

---

### 02-practice-questions.js

Practice problems based on control flow:

* grading system using conditions
* rock-paper-scissors logic
* switch fall-through behavior

Focus is on:

* writing optimized conditions
* avoiding unnecessary checks
* understanding execution flow

---

## Key Takeaways

* Conditions should be ordered logically for clarity
* Early return helps reduce nesting and improves readability
* switch requires break to avoid unintended fall-through
* Clean control flow leads to more predictable code
