# Loops in JavaScript

This folder focuses on repetition in JavaScript using different looping constructs.

The goal is to understand how loops work, when to use each type, and how to control their execution effectively.

---

## Files

### 01-loops.js

Covers basic looping constructs:

* for loop
* while loop
* do-while loop

Also includes:

* loop structure (initialization, condition, update)
* use of `break` to stop a loop
* use of `continue` to skip iterations

---

### 02-practice-questions.js

Practice problems based on loops:

* printing number ranges
* even and odd number logic
* multiplication tables
* sum of numbers
* divisibility checks

Also covers:

* counting conditions inside loops
* early stopping using `break`
* skipping values using `continue`
* handling user input with loops

---

## Key Takeaways

* for loop is best when the number of iterations is known
* while loop is useful when execution depends on a condition
* do-while runs at least once regardless of condition
* break stops the loop completely
* continue skips the current iteration
