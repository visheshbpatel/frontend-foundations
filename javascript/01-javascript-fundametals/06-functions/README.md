# Functions in JavaScript

This folder focuses on functions, which are one of the core building blocks of JavaScript.

The aim is to understand how functions work, how they are used in different forms, and how they help in writing reusable and structured code.

---

## Files

Additional concepts:

* first-class functions
* higher-order functions
* pure vs impure functions
* closures
* lexical scoping

* hoisting differences

## Key Takeaways

* Functions help in writing reusable and modular code
* JavaScript treats functions as values (first-class functions)
* Closures allow functions to remember their outer scope
* Higher-order functions are widely used in modern JavaScript
* Understanding hoisting and scope is important for avoiding bugs
