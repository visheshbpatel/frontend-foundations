# Arrays in JavaScript

This folder focuses on arrays, one of the most commonly used data structures in JavaScript.

The goal is to understand how arrays store data, how they behave as reference types, and how to use built-in methods effectively.

---

## Files

### 01-arrays.js

Covers the basics of arrays:

* creating arrays
* accessing elements using index
* modifying values
* array length

Also includes:

* arrays as reference types
* storing multiple data types
* checking arrays using `Array.isArray()`

---

### 02-arrays-methods.js

Covers commonly used array methods:

* push, pop, shift, unshift
* splice, slice
* sort, reverse

Higher-order methods:

* forEach
* map
* filter
* reduce
* find
* some
* every

Also includes:

* difference between methods that modify original array and those that return new arrays
* sorting behavior and common mistakes

---

### 03-practice-questions.js

Practice problems to strengthen understanding:

* basic array operations
* inserting and removing elements
* slicing and extracting data
* sorting and reversing

Also includes:

* using map, filter, reduce for transformations
* boolean checks using some and every
* destructuring and spread operator

---

## Key Takeaways

* Arrays are reference types, changes affect all references
* Some methods modify the original array, others return new arrays
* map, filter, and reduce are important for real-world coding
* Understanding array behavior helps in writing efficient logic
