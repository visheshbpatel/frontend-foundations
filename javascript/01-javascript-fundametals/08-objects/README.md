# Objects in JavaScript

This folder focuses on objects, which are used to store structured data in key-value pairs.

The goal is to understand how objects work, how to access and manipulate data, and how they behave as reference types.

---

## Files

### 01-objects.js

Covers core object concepts:

* creating objects
* accessing values using dot and bracket notation
* dynamic key access
* nested objects

Also includes:

* destructuring
* looping using `for-in`
* object utility methods (`keys`, `values`, `entries`)
* shallow copy using spread and `Object.assign()`
* deep cloning basics
* optional chaining
* computed properties

---

### 02-practice-questions.js

Practice problems based on object concepts:

* creating and modifying objects
* accessing nested properties
* dynamic property access
* destructuring complex objects

Also includes:

* looping through objects
* using `Object.entries()`
* shallow vs deep copy
* optional chaining for safe access
* computed properties in real scenarios

---

## Key Takeaways

* Objects store data as key-value pairs
* Keys are treated as strings internally
* Dot and bracket notation serve different use cases
* Objects are reference types, copying shares reference
* Deep cloning is required for nested structures
* Optional chaining helps prevent runtime errors
