# JavaScript Fundamentals

This repository contains my notes and practice code while learning the core concepts of JavaScript.

The focus is on understanding how JavaScript behaves, writing clean logic, and building a strong foundation.

---

## Topics Covered

### 01. Variables & Declaration

* var, let, const
* scope basics
* hoisting and temporal dead zone
* reassignment and redeclaration

### 02. Data Types

* primitive vs reference types
* dynamic typing
* type coercion
* truthy and falsy values

### 03. Operators

* arithmetic, comparison, logical
* assignment and unary operators
* ternary operator
* operator behavior and edge cases

### 04. Control Flow

* if, else if, else
* switch case
* early return pattern
* logical conditions

### 05. Loops

* for, while, do-while
* break and continue
* common looping patterns

### 06. Functions

* function declaration and expression
* arrow functions
* parameters and arguments
* closures and higher-order functions
* pure vs impure functions
* IIFE and hoisting

### 07. Arrays

* array basics and operations
* built-in methods (map, filter, reduce, etc.)
* destructuring and spread
* common mistakes and patterns

### 08. Objects

* object creation and access
* nested objects
* destructuring
* looping and object methods
* shallow vs deep copy
* optional chaining

---

## Goal

* Build strong JavaScript fundamentals
* Understand concepts instead of memorizing
* Practice consistently and improve logic
