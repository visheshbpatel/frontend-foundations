# DOM Learning (JavaScript)

This folder contains my practice and notes for learning the DOM (Document Object Model) in JavaScript. The code is written in a simple and clear way to understand the core concepts without unnecessary complexity.

## Folder Structure

01-dom-selection.js
Covers different methods to select elements from the HTML document.

02-dom-manipulation.js
Includes changing text, HTML content, and working with attributes.

03-dom-dynamic.js
Focuses on creating, adding, and removing elements dynamically.

04-dom-styling.js
Covers styling elements using JavaScript and working with classList.

05-practice-questions.js
Contains important DOM questions with answers and code for practice.

## Topics Covered

1. Element selection
2. Text and HTML manipulation
3. Attribute handling
4. Dynamic DOM manipulation
5. Styling using JavaScript
6. Practice questions for revision

This is a learning repository.
