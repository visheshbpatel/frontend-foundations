# Events Handling (JavaScript)

This folder contains my practice and notes for learning event handling in JavaScript. The focus is on understanding how events work and how to handle them using simple and clear code.

## Folder Structure

01-event-binding.js
Basic event binding using addEventListener.

02-common-events.js
Covers commonly used events like click, input, change, keyboard, and mouse events.

03-event-object.js
Explains the event object and properties like target, type, and preventDefault.

04-event-bubbling-capturing.js
Covers event flow including bubbling and capturing.

05-practice-questions.js
Contains practice questions with code implementations.

index.html
Used for testing all event handling concepts.

## Topics Covered

1. Event binding
2. Common events
3. Event object
4. Event bubbling and capturing
5. Practice questions
