# Form Validation (JavaScript)

This folder contains a simple login form validation project using HTML, CSS, and JavaScript. The goal is to understand how to validate user input using JavaScript instead of relying on browser default validation.

## Folder Structure

index.html
Contains the structure of the login form.

styles.css
Handles the styling of the form and layout.

script.js
Implements validation logic for email and password fields.

## Features

1. Validates email format using regex

2. Validates password with rules:

   * Minimum 8 characters
   * At least one uppercase letter
   * At least one lowercase letter
   * At least one number
   * At least one special character

3. Shows custom error messages

4. Prevents form submission if inputs are invalid

5. Displays success message on valid input

6. Clears input fields after successful submission

## Concepts Used

1. Event handling (submit event)
2. preventDefault()
3. DOM manipulation
4. Regex (Regular Expressions)
5. Form handling using JavaScript
