# Timers and Intervals (JavaScript)

This folder contains my practice and small project based on JavaScript timers and intervals. It focuses on understanding how time-based functions work and how they are used in real UI behavior.

## Folder Structure

01-timeout-interval.js
Covers basics of setTimeout, setInterval, clearTimeout, and clearInterval.

index.html
Basic HTML structure used to test the project.

styles.css
Styling for the progress UI.

script.js
Implements countdown and download progress simulation using intervals.

## Features

1. Countdown before starting download
2. Progress bar simulation using setInterval
3. Dynamic percentage update
4. Stops automatically when progress completes
5. Updates UI based on progress state

## Concepts Used

1. setTimeout and setInterval
2. clearTimeout and clearInterval
3. DOM manipulation
4. Event loop basics
5. Time-based UI updates

## Note

This is a learning project.
Concepts and code will be refined over time as understanding improves.
