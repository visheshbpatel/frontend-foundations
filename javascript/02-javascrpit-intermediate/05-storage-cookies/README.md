# Storage and Cookies (JavaScript)

This folder contains my practice and small project based on browser storage. It covers localStorage, sessionStorage, and cookies, along with a simple theme toggle implementation.

## Folder Structure

01-storage-cookies.js
Covers basics of localStorage, sessionStorage, and cookies.

index.html
Basic HTML structure used to test the project.

styles.css
Styling for the theme toggle UI.

script.js
Implements theme toggle using localStorage and system preference.

## Features

1. Store, fetch, update, and remove data using localStorage
2. Store arrays using JSON.stringify and retrieve using JSON.parse
3. Basic understanding of sessionStorage
4. Access and set cookies using document.cookie
5. Theme toggle with persistence using localStorage
6. Uses system theme preference if no saved theme is found

## Concepts Used

1. localStorage and sessionStorage
2. Cookies
3. JSON.stringify and JSON.parse
4. DOM manipulation
5. Event handling
6. Browser APIs (matchMedia)
